# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Fail-closed first-boot provisioning with per-device setup tokens and AP passwords.
- Per-device ECDSA TLS identities for ESP32-S3 and ESP32-P4 targets.
- Deterministic, manifest-driven firmware packaging and release secret scanning.
- Three-board CI builds and provenance-attested prerelease assets.

### Changed

- Public builds no longer read private parent-repository credentials or embed shared secrets.
- Factory reset and physical serial recovery now have explicit, documented semantics.

### Security

- Open hardening findings tracked as issues #1-#15 (watchdog, crash diagnostics,
  panic-safety, HTTPS lifecycle, emergency AP credentials, LittleFS data wipe,
  packet pipeline, init rollback, time synchronization, PSRAM requirement,
  boot testability).

- Passive IDS, vulnerability scanner and rate-limited fuzzing for Modbus TCP,
  S7, PROFINET, OPC UA and EtherNet/IP.
- Web dashboard (HTTPS) with configuration, diagnostics, logging, signature
  management and reporting.
- Ethernet support for ESP32 (T-POE Pro), ESP32-S3 (W5500) and ESP32-P4 (Waveshare).

## [0.1.0] - Unreleased

- Initial public release. Firmware binaries are attached to the first tagged
  release generated by the release workflow.
