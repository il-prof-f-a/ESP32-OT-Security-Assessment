    EtherNet/IP (CIP)

    Configurazione Connessione

    Configurazione Sicurezza

    Verifica se il dispositivo supporta CIP Security (autenticazione/crittografia)
    Rileva explicit messaging in chiaro (GetAttributeSingle senza crittografia)
    Testa se è possibile scrivere attributi senza autenticazione

    IDS Configuration

    Rileva tentativi eccessivi di RegisterSession (>10 in 60s)
    Rileva richieste SendRRData eccessive (>50 in 30s) - possibile DoS
    Rileva operazioni di scrittura CIP eccessive (SetAttributeSingle/Reset)
    Rileva attività di ricognizione (ListIdentity/ListServices eccessivi)
    Rileva pattern di errori sospetti (>15 status!=0 in 30s)
